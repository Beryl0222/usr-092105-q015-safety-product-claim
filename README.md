# 安全用品宣传举证

本项目实现“宣传声明举证与传播处置”领域：以每一句可传播声明为核对单位，关联产品型号、认证范围、报告有效期、允许表述、禁用比较、脚本、直播、达人授权、剪辑来源、投放账户、审核决定、下架传播与申诉材料。系统只判断现有证据能否覆盖声明，不替监管作行政认定。

## 领域资料

- `contracts/domain.schema.json`：事件信封与本领域允许的聚合、事件类型。
- `data/sample.json`：一条可用于本地联调的中文样例。
- `data/case-foldable-helmet.json`：折叠头盔案例的完整事件流（直播下架、短视频派生、证据过期、申诉）。
- `src/`：领域引擎，无外部依赖。
- `tests/`：契约校验与案例全流程测试。

事件由 `event_id` 唯一标识，`aggregate_id` 指向业务对象，`version` 从 1 开始递增，`occurred_at` 保留真实发生时间。来源系统重试时必须沿用原事件标识，重复抓取按 `event_id` 去重。

## 模块

- `src/validator.js`：事件信封与领域枚举校验。
- `src/store.js`：事件入仓，幂等去重，按事实时间排序。
- `src/projector.js`：事件流投影为领域状态（声明、证据、素材、投放、决定、申诉、更正说明）。
- `src/coverage.js`：覆盖判定。证据过期或撤销只影响对应型号、声明和时段。
- `src/derivative.js`：派生物识别。原素材停投后，按文本实质相同与剪辑来源持续发现派生投放；已有自身标注的剪辑不被株连。
- `src/enforcement.js`：暂停下传与消费者更正说明。暂停仅限决定指向的声明与型号，不误伤其他合法型号；更正说明必须指明产品、原表述与适用场景。
- `src/view.js`：处置视图，从任一句口播展开型号、证据与全部派生投放。
